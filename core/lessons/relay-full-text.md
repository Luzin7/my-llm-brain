---
name: relay-full-text
description: Relay an approved decision as its full text in the message, never as a pointer to a plan file
type: lesson
---
When the user approves a recommendation, the message that carries it forward states the choice, its scope and its parameters. "As in the plan, section 3" forces the next reader to find the file, guess the version and rebuild the decision.
**Why:** a pointer hides the decision inside a document that may have changed, and the user cannot check what was actually relayed.
**How to apply:** copy the approved text itself into the relay, verbatim where the user wrote it, with scope and approval date. A file path may follow the text as a reference, never replace it.
